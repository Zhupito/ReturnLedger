# Related work and scope

The public search found other retail assistants combining policy documents, retrieval and tools. It cannot establish that every similar implementation has been identified.

- Sierra's τ-bench retail environment includes a written policy and tools for customer-service tasks such as returns and exchanges. [Retail policy](https://github.com/sierra-research/tau-bench/blob/main/tau_bench/envs/retail/wiki.md)
- A public customer-support chatbot combines policy retrieval, citations and business tools. [Customer Support AI Chatbot](https://github.com/Abhinav-kanduri/Customer-Support-AI-Chatbot)

ReturnLedger focuses on retrospective, read-only auditing. It replays a second calculation using the payment date to expose false alarms and attaches both edition-specific evidence and a reproducible deadline to each decidable order. The fictional policy text, ledger and expected outcomes were created for this repository. No claim of exclusive invention is made.
